MODEL NOTES / STAGE 02

阶段二：六自由度与动态悬架

01本期范围

本页面是 DESIGN.md 阶段二的交互演示：在阶段一的外观、倾斜路面和静态四角载荷之上，加入车体六自由度、四角机构反解的弹簧—阻尼器和前后防倾杆动态。车体不再直接贴合路面，而是在悬挂力、重力和接触摩擦作用下积分升沉、俯仰、侧倾、纵移、横移与横摆。

  • 六自由度刚体：三轴平动、三轴转动，四元数姿态，固定步长 2 ms 半隐式积分
  • 四角双横臂、推杆、摇臂与弹簧—阻尼器按硬点实时反解，线圈长度直接产生弹簧力与阻尼力
  • 前后横向扭杆式防倾杆按左右行程差产生等大反向作用力
  • 四轮接地点保持在倾斜平面内，切向库仑摩擦承担坡面驻车与滑移
  • 车身、车轮、摇臂、推杆、弹簧—阻尼器与载荷箭头共享同一动态姿态

阶段三、四（轮胎侧偏/纵滑、后轴驱动、空气动力学）尚未接入。当前悬架仍为等效轮心力学加端点绑定的视觉运动学；横臂不参与载荷计算，轮胎切向力只用于驻车/滑移，不产生侧偏力。转向只驱动前轮和拉杆，不产生侧向力。

02动力学求解

路面局部坐标取 x 向前、y 沿法向、z 向右。车体状态为参考点位置 r = (x, y, z)、速度 v、姿态四元数 q 和车体角速度 ω。四元数按 q̇ = ½ q ⊗ (0, ω) 推进，欧拉角按 R = Ry(ψ)Rz(θ)Rx(φ) 提取；正俯仰抬车头，正侧倾压低右侧，正横摆向左转。

m dv/dt = m g + ΣNi ey + Σfi + Fimpulse
ICG dω/dt + ω × (ICGω) = Σ(ri − rCG) × Fi

每个角的弹簧力为 Ni = Ni0 − kw,iδi − cw,iδ̇i + Farb,i，其中 δi 是车体在轮心处的法向位移，负值表示弹簧压缩；Ni0 是设计姿态角重量，kw 是轮心等效刚度，cw = 2ζ√(kwmi) 由阻尼比 ζ 换算。防倾杆取左右行程差 Δ = δL − δR：

Farb,L = −kaΔ，Farb,R = +kaΔ

运动比 i 由四角机构实时反解，不再作为输入：ks = kw/i2，cs = cw/i2。弹簧力取实际线圈长度 Fs = ks(L − Lref) 加阻尼 csL̇，再经机构雅可比换成轮心力。页面里的弹簧伸缩量、横臂、拉杆、摇臂和防倾杆均由同一次反解驱动，因此画面与载荷是同一组数。

车轮中心保持在路面上方一个轮胎半径处，车身相对路面的姿态产生四角行程。积分采用半隐式欧拉，步长固定为 1/500 s；渲染帧只累积并执行整数个子步，因此改变刷新率不会改变物理结果。脉冲试验在 0.12 s 内施加垂向力，用来观察弹簧—阻尼器和防倾杆的瞬态。

切向接触使用简化的库仑摩擦：静止且所需切向力不超过 μΣNi 时按法向载荷比例分配静摩擦并保持平面速度为零；超过容量或已经滑移时按 μNi 施加动摩擦。该模型只承担坡面驻车与滑移，不产生轮胎侧偏力，阶段三将替换为完整的轮胎滑移模型。

03阶段二验收映射

A
六自由度车体

位置、速度、四元数姿态与角速度完整积分；水平路面收敛到设计姿态，倾斜路面收敛到与静力解一致的载荷。

B
四角弹簧—阻尼器

设计位置轮心刚度与阻尼比可调；运动比由机构反解并随行程变化；脉冲后按阻尼比衰减，不出现非预期持续振荡或发散。

C
防倾杆动态

左右同向行程不产生扭转；反向行程产生等大反向力；提高硬度抑制侧倾，并改变前后轴侧倾载荷转移。

D
机构与视觉同步

车身六自由度带动车轮平面位置与横摆；杆件端点跟随车体与立柱；弹簧、摇臂、推杆与载荷箭头使用同一次求解结果。

E
数值与交互

固定步长 500 Hz，渲染帧率不改变结果；暂停、重置、三种脉冲可复现；低附着时六自由度滑移并给出警告。

    05操作与约定

    • 拖动 环绕观察（场景跟随指针），滚轮以光标为中心缩放，右键/中键或 Shift+拖动平移，双击重置

    • X 切换车身剖视，M 机构剖视（转向 → 传动 → 前/后防倾杆），R 返回总览

    • 动态 参数面板底部可暂停、重置姿态，或施加垂向、侧倾、俯仰脉冲
    • 单位 遥测面板可在 N 与 kg 等效之间切换；kg 值按 g = 9.80665 m/s² 换算
