阶段一：外观与静态底盘

01本期范围

本页面是 DESIGN.md 阶段一的交互演示：建立可辨认的现代开轮方程式赛车外观与主要尺寸，建立可整体倾斜的路面、质心与四轮静态位置，并计算水平及倾斜路面上的四角静态法向载荷。

  • 程序化车体、前后翼、Halo、侧箱、底板与扩散器
  • 前后双横臂、推杆/拉杆、摇臂、弹簧—阻尼器、转向机与扭杆式防倾杆
  • 前轴转向柱与左右横拉杆、后轴差速器与左右半轴、四个独立车轮
  • 双轴倾斜路面，重力方向保持世界竖直
  • 四角轮载、轴荷分配、附着需求与模型自检实时显示

阶段二至四（六自由度动态、轮胎滑移与驱动、空气动力学调参）尚未接入。当前悬架杆件为视觉运动学绑定，不强制刚性杆长约束；阶段二将由共享几何模块替换。

02静力求解

路面局部坐标取 x 向前、y 沿法向、z 向右。设平面法向与竖直方向夹角为 β，车重 mg 在路面法向的分量为 Ntot = mg cosβ。重力线在路面上的投影点为 P：

P = CG + t·groad，t = −hCG / groad,y

四角支反力满足力与力矩平衡：

ΣNi = Ntot
ΣxiNi = NtotPx
ΣziNi = NtotPz

每个角由等效轮心弹簧支撑，弹簧力 Ni = Ni0 − ki(h + xip − zir) + Farb,i，其中 h、p、r 为车体相对路面的升沉、俯仰和侧倾。防倾杆在左右轮心产生等大反向的附加力，只进入侧倾方程，其等效侧倾刚度为 Karb = kaFtF2 + kaRtR2。将弹簧力代入平衡式，得到关于姿态的三元一次方程组；四角载荷由此唯一确定。水平路面上解为设计姿态，轮载等于由质心位置分配得到的静态角重量。

防倾杆不是连接左右车轮的刚性横梁：它是一根横置扭杆，两端杠杆臂朝同一侧伸出，经连接杆接到摇臂吊耳。左右同向运动时扭杆自由转动，单轮跳动或侧倾时才受扭。可调式的一根杠杆臂为扁平弹簧钢叶片，绕自身纵轴旋转改变弯曲刚度；页面以 0–100% 硬度表示这一调节，叶片转角按 θ = arccos√p 计算。

切向重力分量 mg sinβ 由轮胎静摩擦承担。页面按各轮法向载荷比例分配切向力，并给出均匀附着需求 μreq = tanβ；该简化不校核坡面偏航和四轮独立附着。

03阶段一验收映射

A
外观与主要尺寸

可辨识的开轮单座方程式赛车；轴距、前后轮距、轮胎半径可调。

B
倾斜路面与静态位置

纵坡/横坡独立调整；四轮接触点位于路面，重力保持世界竖直。

C
水平与倾斜静态轮载

水平状态按质心分配；倾斜后轮载满足法向力与力矩平衡，并显示对水平基准的变化。

D

E
转向、传动与防倾杆

前轴齿轮齿条、转向柱和横拉杆；后轴差速器与半轴；横向扭杆、同向杠杆臂、连接杆和叶片式硬度调节。
