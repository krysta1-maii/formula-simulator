## 1. 范围与结论

本轮关闭当前版本中已复现的物理初始化、失效力链、低速接触、页面生命周期和测试门禁问题，并整理全仓文档。轮胎侧偏/纵滑、车轮自转、驱动、空气动力和下一阶段架构不在本轮范围内；[未来路线草案](../formula_simulator_next_stage_roadmap.md)仍是未批准材料。

最终 `npm run ci` 全部通过，审计 51/51 且基线匹配。性能预算和预览截图生成也通过。下列“关闭”均有当前工作树回归证据；未覆盖的旧 P3、真实设备差异和模型固有简化不在关闭声明内。

## 5. 验证边界与未关闭事项

1. **模型边界未改变。** 当前仍是单簧上质量、等效轮心和倾斜平面试验台，没有真实非簧载质量、车轮离地、轮胎滑移、驱动或气动。
2. **回退不是正常物理解。** ±20 kN 是失效时的有限安全边界，不能据此宣称不可达机构仍有正常精度。
3. **守恒断言有适用范围。** 当前验证 1 s、非主轴 `ω=(1,1,1)`，能量和角动量误差门槛为 0.25%；高角速度、长时间积分误差仍需另行评估。
4. **初始平衡有数值容差。** 18° 初始化达到 0.01 N/Nm 验收门槛，不是机器精度零残差。
5. **联合低速摩擦有适用条件。** 联合求解仅在低速、四轮承载时启用，超出范围仍使用原库仑滑移分支；5000 组防反向断言和积分停止投影只针对同一低速判据，不外推到高速或任意耦合状态。
6. **包络是采样验证。** 不是连续网格碰撞证明，也不覆盖全部内部件相互干涉。
7. **生命周期验证使用合成 BFCache 事件。** 未单独执行真实跨页后退；真实手机、屏幕阅读器和真实 GPU 帧率也不在本次实测范围内。
8. **版本矩阵有限。** 本地实测 Node 24.22.1 + Chrome 156；[CI 工作流](../../.github/workflows/ci.yml)使用 Node 22 + 稳定 Chrome，但本报告不宣称远程工作流已经运行，也不宣称 Node 18/20 已实测。
9. **旧评审不逐项清零。** P2-09/P2-10 的已知缺口已补，其他低优先级 P3 和新增未知输入组合不能由本轮全绿推定全部关闭。
