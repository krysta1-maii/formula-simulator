# 0.3.0 对抗评审到 0.4.x 的状态映射

> 本说明只补充跨版本状态，不改写原报告。原评审基线为 0.3.0 / `45983ca`；当前交付以根目录 [README](../../../README.md)、[DESIGN](../../../DESIGN.md) 及 [0.4.1 最终验收](../../plan/acceptance.md) 为准。0.4.1 已完成当前收口；具体证据和仍然有效的限制以验收记录第 3、5 节为准。

## 0.4.1 当前收口关闭项目

以下项目已在 [0.4.1 验收记录](../../plan/acceptance.md) 第 2 节逐项登记修复与回归证据：

- P1-01/P2-04：质心调整、重置和恢复默认；
- P1-02：复合坡面低速重新驻车；
- P1-03、P2-16～18：相机键盘路径、焦点、选中态和对比度；
- P2-01：不可达机构不再进入正常 mechanism 力链，改用有界、可观测回退；
- P2-03：自检设置快照、缓存和旧 revision 取消；
- P2-05～08：子步、审计、几何等待和 Chrome 门禁；
- P2-11：dispose、RAF、监听器和 BFCache 合成事件；
- P2-12～15：面板安全区、窄屏取景、自检行和提示布局；
- P2-19：垂向脉冲改为作用于质心；
- M6 遗留的守恒断言和完整 teardown 自动化缺口。

P2-09/P2-10 的已知浏览器编排和断言缺口已补充针对性回归，但不据此宣称所有输入组合或其他低优先级 P3 都已关闭。

## 其余发现的阅读口径

原报告中的复现步骤、源码行号、测试数量和发布建议均属于 0.3.0 历史记录。当前代码已经跨版本变化，不能用旧行号或旧计数代替最新验收证据。回退精度、守恒验证时长、联合摩擦适用范围、包络采样、真实跨页后退、真实设备与版本矩阵等限制，仍以 [0.4.1 验收记录](../../plan/acceptance.md) 第 5 节为准。
