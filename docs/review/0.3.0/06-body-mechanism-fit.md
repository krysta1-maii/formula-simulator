## 2. 画面证据

- 前轴剖视特写：前弹簧—减振器整体位于半透明单体壳顶面之上，减振器杆穿过蒙皮；前防倾杆横置于壳体上方。
- 后轴剖视特写：后弹簧—减振器从变速箱顶部穿出，位于发动机罩外侧上方；后防倾杆同样在罩体之上。
- 对照 README 的 `docs/03-xray.png`：同一现象在正式文档截图中已经存在（后轴弹簧明显高于发动机罩），并非本轮新引入。

## 3. 根因

1. 悬架硬点在 `src/js/03-suspension.js:24-37` 独立定义，车体在 `src/js/20-car.js:740-770`（单体壳）、`:917-927`（发动机罩）独立放样；两者没有共享包络约束，也没有构建期/测试期校验。
2. 前减振器上车体点 y=0.79 m，而该处单体壳顶面仅 0.51–0.55 m；前防倾杆 y=0.715 m 也在顶面之上。后减振器 y=0.66 m，变速箱顶面 0.435 m、发动机罩约 0.47 m。
3. 车体是封闭曲面，没有为推杆、减振器、防倾杆轴承座预留开口、凸包或安装座；机构穿过蒙皮时没有对应结构。
4. 代码注释 `src/js/22-car-dynamics.js:848` 写“inside bodywork, visible in x-ray”，DESIGN.md:199 写防倾杆“都放在车体内部”，均与几何不符。

关键提交是 `fbb401d`（`feat: 悬架动力学改为机构实时反解 0.2.0`）。提交说明原文写：“**前摇臂与弹簧安装点上移以覆盖行程，后轴改为低位推杆**”。同一次提交对 `20-car.js` 只删除了一个未使用的 `V` 辅助函数，单体壳、发动机罩、侧箱的放样数据都没有改；`fbb401d..HEAD` 也没有再改车体包络。

这次改动不是“为了圈速/运动表现”，而是为了机构学与力学的真实性：

1. 旧版用固定运动比 0.58/0.62，杆件只做视觉近似；0.2.0 改为每子步牛顿反解，运动比取当前机构导数（0.52/0.32）。
2. 旧版前摇臂的 damper 臂与 push 臂反向，减振器又接近水平，bump 时线圈会被拉长；0.2.0 新增断言 `bump shortens every coil and droop extends it`，要求 bump 压缩、droop 拉伸。
3. 为满足压缩方向与 ±25 mm 行程闭合，前摇臂和弹簧安装点上移，后轴改为低位推杆（pushrod），减振器从近水平变成近垂直/大倾角。

同一改动还把后轴从高位拉杆（`wheelLocal.push` 的 y 由 +0.195 m）改为低位推杆（−0.185 m），但 `22-car-dynamics.js:845` 仍把后轴链接标记为 `pullrod`，`DESIGN.md:50/133` 仍写“后轴采用拉杆”；这是同一次改动的命名/文档残留（P3），不影响求解。

因此，物理改动本身是合理的；问题在于机构上移后没有同步修改车体包络。旧版 `docs/03-xray.png` 中减振器还在鼻锥/发动机罩内，0.2.0 的提交同时更新了这张截图，但新截图里弹簧已经穿出车体——这次“文档截图更新”实际上把回归写进了交付物。旧版截图归档为 [evidence/body-fit-old-8e5c92a-xray.png](evidence/body-fit-old-8e5c92a-xray.png)，新旧对比见 [evidence/body-fit-old-vs-new.png](evidence/body-fit-old-vs-new.png)。

## 4. 影响

- 剖视（X / M）是 README 的主要展示功能，也是“可见机构与载荷共用同一次求解”的卖点；当前剖视把“内部悬架”画在车体外面，机构的安装关系不可信。
- 正常视图隐藏内部组，因此日常驾驶画面不受影响；但前推杆上端在正常视图中也高出蒙皮 37 mm，摇臂/减振器被隐藏后，推杆在车体一侧看起来没有附着点。
- 动力学不受影响：硬点仍是车体坐标系中的合法作用点，弹簧力、阻尼力、防倾杆力的数值与收敛性不变；这是视觉/结构保真缺陷，不是物理错误。
- 文档一致性：DESIGN 20.6 对防倾杆“在车体内部”的声明不成立；README 剖视截图本身展示了该缺陷。

## 5. 修复方向

按优先级：

1. **把机构放回车体包络内**（首选）：前轴把摇臂/减振器下移并改为纵向或横向布置，使减振器上车体点低于单体壳顶面；后轴把减振器收入变速箱/发动机罩内，或加宽罩体形成可容纳弹簧的整流罩。该方案会改变硬点、运动比与弹簧刚度换算，必须重跑运动学、静平衡、脉冲与确定性回归。
2. **扩大车体并补结构**：在前后轴位置增加局部凸包/整流罩与轴承座、减振器塔顶，车体开口处补法兰；保持硬点不变，但需重新检查车体与轮胎、地面、前后翼的间隙。
3. **不要仅隐藏机构**：剖视功能的目的就是展示内部结构，简单隐藏不能解决“机构与车体不匹配”。
4. **增加自动校验**：对每个内部件采样顶点，断言其位于车体闭环网格内（射线奇偶）或低于局部蒙皮；对车体侧杆端断言与蒙皮距离 ≤10 mm；对 DESIGN 声明的“内部”组件单独断言。该校验可直接复用 `.tmp-review/lead/probe-body-fit.mjs` 的射线方法。

## 6. 首轮审阅为何漏掉

视觉报告验证了杆长闭合、接地点、轮胎穿透、相机取景、资源重建与剖视截图，但没有“内部件是否位于车体包络内”的判据；剖视截图只做了定性观察，1440×813 的整机视角下“弹簧在车体上方”容易被读成“安装在车体上”。这说明首轮的视觉检查清单缺少“包络/装配关系”一类断言。后续审阅应把“机构—车体—轮胎—地面”的相互包络列为独立检查项，而不是只看各自的闭合与投影。

## 7. 置信度与限制

- 置信度：高。硬点坐标来自源码，蒙皮高度由真实场景网格射线实测，二者独立；截图与数值一致。
- 限制：只测默认参数、水平路面、静平衡姿态；未测大倾角、极限行程、转向 ±15° 下机构与车体的动态间隙；未做逐三角形包含判定，射线法对薄壁/开口网格可能有边界误差，但本项差值在 29–300 mm 量级，不影响结论。
