# FS-01 悬挂重构说明（0.4.0）

## 1. 目标与布置

本次重构保持既有方程式赛车的车体放样、前后翼、轮距和轴距，不通过放大车体来遮盖悬挂。单体壳和发动机罩截面只是从 `20-car.js` 移到 `buildBodyworkProfiles()` 共享，截面数值没有放宽。

悬挂采用现代方程式赛车常见的六杆角点：四根叉臂杆、一根转向横拉杆或后 toe link、一根推/拉杆。每轮只有一个摇臂，推/拉杆是摇臂唯一的外端驱动。前轴为下部轮架到高摇臂的推杆，后轴为上部轮架到低摇臂的拉杆。每角使用一根近水平、沿车身纵向布置的螺旋弹簧—阻尼器。

| 项目 | 前轴 | 后轴 |
| --- | --- | --- |
| 外端驱动 | 下部轮架推杆 | 上部轮架拉杆 |
| 摇臂高度（设计车体系） | 0.476 m | 0.220 m |
| 弹簧设计长度 | 约 0.395 m | 约 0.358 m |
| 弹簧轴线 | 单体壳内纵向卧置，约 10° 倾角 | 变速箱至发动机罩内纵向卧置，接近水平 |
| 设计运动比 | 约 1.268 | 约 1.006 |
| 轮心率 | 140 N/mm | 160 N/mm |
| 换算线圈刚度 | 约 87 N/mm | 约 158 N/mm |

普通视图只显示上下叉臂、推/拉杆、横拉杆、后半轴、轮架和制动/车轮机构，以及这些杆件穿过蒙皮时使用的衬套。摇臂、弹簧—阻尼器、防倾杆、齿条和差速器均在车体内，剖视时显示。普通视图也不再遗留减振器上下球头。穿壳衬套独立放在 `suspensionSkinMounts`，不混入车内总成。

默认 3.55 m 轴距的车体截面与后承载壳尺寸保持原值。改变轴距时，后轴会相对发动机罩移动，因此变速箱承载壳按 `1.20 × |L − 3.55|` 向前增加纵向安装段；它用于保持同一车内机构的装配空间，默认外形不增大。

## 2. 单一几何与力链路

`03-suspension.js` 的 `buildCornerData()` 是四角硬点唯一来源。轮架仍由 `thL/thU/spin` 三个未知量闭合上下球头、横拉杆和接地点约束；推/拉杆长度用两圆交点闭式反求摇臂角。没有为外观另设一套近似角度。

弹簧长度和速度通过机构雅可比换算到轮心。设计位置采用

```
i = 弹簧行程变化量 / 轮跳
k_s = k_w / i_0²
c_s = c_w / i_0²
```

这里的 `i` 与部分资料中“轮跳/弹簧行程”的 MR 定义互为倒数。轮心输入刚度保持不变，改变的是实际摇臂传动比和内置总成参数。

力评估记录 `coilSource = mechanism | fallback | none`。正常工况下，遥测、弹簧动画和力使用同一个机构长度；求解回退时，轮架与接地点先投影回路面，再由同一轮架重算摇臂和弹簧长度；力、遥测与动画共用这组投影结果。只有阻尼速度使用设计斜率，叉臂和横拉杆的未闭合状态继续明确降级。

## 3. 转向与传动

齿条位置、套筒和球头由 `body.trackBase` 派生，不再使用另一套硬编码坐标。标定采用 ±60 mm 冷启动扫描和二分，避免历史种子造成分支跳变。水平 +18° 对应齿条约 +32.153 mm，−18°为 −32.153 mm，平均轮角误差小于 10⁻⁴°。

横拉杆内点接近前视瞬心连线。±25 mm 轮跳时，前轴跳动转向约 0.088°，后轴约 0.023°。后差速器和半轴仍由同一轮架位姿驱动，本阶段不施加驱动扭矩。

## 4. 车体包络验证

车体放样和包络检查共享 `buildBodyworkProfiles()`。浏览器诊断接口 `window.FSApp.getSuspensionPackaging()` 使用四类封闭网格：

1. 单体壳；
2. 发动机罩；
3. 变速箱；
4. 后悬挂承载结构。

探针对摇臂、弹簧、减振器、防倾杆、齿条、差速器和球头采样实际三维顶点，并用射线奇偶规则判断是否位于任一封闭体积内。另检查摇臂与减振器硬点、弹簧卧式倾角与纵向分量、推/拉杆类型、防倾杆—杠杆连续性和普通/剖视可见性。测试不是简单隐藏内部件，也不要求把外部推/拉杆和半轴算进车体。每个网格最多取约 72 个顶点，因此这是采样验证，不是连续网格碰撞证明，也不代替内部件之间的相互干涉检查。

执行：

```bash
npm test
npm run test:invariants
npm run test:suspension
```

`test:suspension` 覆盖普通视图、剖视、垂向脉冲、18°转向叠加俯仰、侧倾，以及 3.20/3.70/3.90 m 轴距重建；同时检查杆件闭合和“可见弹簧压缩量 = 力链路压缩量”。

## 5. 模型边界

本实现不是某一辆 F1 赛车的零件复刻。主弹簧仍是线性螺旋弹簧，未模拟现代 F1 常见的扭杆主弹簧、第三弹簧、惯容器或非线性阻尼阀系；防倾杆仍是等效轮心刚度与可见扭杆机构。车体为单簧上质量，未加入非簧载质量、轮胎离地、杆件弹性、衬套和万向节转角约束。上述简化不影响本次要求的几何、载荷和动画使用同一套悬挂解。阻尼速度采用瞬时运动比乘等效轮心速度的近似，不是线圈长度对完整姿态与速度的全导数。

## 6. 0.4.0 验证结果（历史基线）

以下记录只对应 0.4.0 悬挂重构交付，不是 0.4.1 最终验收结果；当前状态以根 README/DESIGN 及最新验收为准。

- Node：静力 50/50、动力学 104/104、物理不变量 31/31、运行时 78/78、dev-server 12/12；
- 浏览器：动态交互、悬挂包络、相机和 UI 45/45 全部通过；
- 悬挂包络：普通、剖视、垂向脉冲、18°转向叠加俯仰/侧倾及 3.20/3.70/3.90 m 轴距，均为 **0/11122 个内部采样点越界**；
- 默认姿态下前/后弹簧倾角约 9.94°/0.10°，叉臂、推/拉杆和防倾杆的杆长残差均显示为 0.0000 mm；
- 完整审计 51 项和性能预算检查通过。

普通外观与剖视分别见 [悬挂普通视图](11-suspension-normal.png) 和 [悬挂剖视](12-suspension-xray.png)。
