## 1. 背景与判定

两份审查报告针对同一提交给出了不同结论。复核后的判定是：B 报告的高优先级物理发现成立，A 报告的整体结论“无影响结果正确性的实质 bug”不成立；A 报告中关于变量遮蔽、开发服务器边界、死代码与命名的一致性问题成立，应予采纳；A 报告的性能项方向正确但数量级高估；两份报告都遗漏了渲染层向物理求解种子回写的耦合。

已复现并确认的问题共 12 项，按性质分为四组：

| 组别 | 缺陷 | 复核证据 |
| --- | --- | --- |
| 物理状态 | B 4.2 非质心参考点积分遗漏旋转耦合 | 无外力、初始侧倾 1 rad/s，1 s 后质心漂移 287.66 mm |
| 物理状态 | B 4.1 摇臂闭合不可达仍进入力计算 | 推杆目标 707.83 mm，可达下限 709.40 mm，残差 4.02 mm，运动比 -4.20，阻尼峰值 30.7 kN |
| 物理状态 | 渲染层回写摇臂角种子 | 同工况回写后阻尼峰值 46.3 kN，运动比 ±7.6；Node 测试不可见 |
| 物理状态 | A 2 变量遮蔽 | simEvaluate 中 state 遮蔽全局参数对象，回退分支语义错误 |
| 接触与坐标 | B 4.3 低速摩擦死区与速度反转 | vx=0.0005 时摩擦为零；vx=0.01 单步后 -0.01746 m/s |
| 接触与坐标 | B 4.4 脉冲作用点混用坐标系 | 横摆 90° 后俯仰脉冲产生车体系 5890 N·m 侧倾；正确物理为 6880.45 N·m 俯仰 |
| 接触与坐标 | B 4.5 两套接地点 | 默认工况差 8.53 mm，10° 姿态差 178.8 mm |
| 运行时 | B 5.1 低帧率静默丢时 | 5 Hz 下 1 s 墙钟推进 0.4 s，应用层截断后 0.25 s |
| 运行时 | B 5.2 几何代际混用 | 3.90 m 轴距下旧硬点与新轮位杆长偏差约 104 mm |
| 运行时 | B 5.3 周期遥测重跑自检并重建 DOM | 静态自检约 22 ms、动态自检约 572 ms（Node），浏览器更慢 |

既有测试全部通过，说明这些缺陷不在现有断言覆盖范围内。施工计划的第一项工作因此是先把缺陷固化为可复现的审计脚本，再逐项修复。

## 2. 范围

### 2.1 本计划包含

1. 物理内核的状态定义、积分方程、求解器协议与失败降级。
2. 接触、摩擦、脉冲与接地点等力与坐标链路的一致性。
3. 固定步长循环的时间语义、几何代际与资源生命周期。
4. 界面可访问性、工具链约束与既有清理项。
5. 文档、自检、遥测与实现的口径同步。
6. 阶段三准入所需的接口冻结与回归基线。

### 2.2 本计划不包含

轮胎侧偏与纵滑、后轴驱动、空气动力学、非簧载质量建模、多体动力学替换、前端框架迁移、全面 TypeScript 迁移。这些属于阶段三及以后，本计划只保证阶段二缺陷修复后接口不再阻碍它们。

### 2.3 不推翻重写的部分

现有视觉资产、单文件构建、离线分发、静力求解器与机构几何、测试分层均保留。施工以定点修正与协议重写为主，不更换渲染方案。

### 2.4 开工前契约冻结

审核确认五份分册在接口字段、脉冲基线、自检数量与工作量上存在 10 项冲突与 6 项追加裁决。开工前先完成一次只改文档的契约冻结提交（B0-0），内容为：状态与角点字段表、ForceEvaluation 与快照契约、UI 字段与检查表行 id、脉冲力臂基线、测试文件归属、npm 命令与退出码。冻结后分册 01–05 只引用不重定义；后续实现偏离契约时，先改契约再改代码。

## 3. 施工原则

1. **证据先行**：每个缺陷先有可复现脚本与失败基线，修复后同一脚本转绿。审计脚本与修复分开提交。
2. **单一契约**：状态、角点、力评估、遥测快照各有唯一 schema；同一物理量只有一个计算点，其余模块只消费结果。
3. **物理层不读渲染**：求解种子、角点状态、几何版本归物理层所有；渲染层只读快照。
4. **失败显式化**：求解失败、几何不可达、时间丢弃都必须进入状态与遥测，不以“有限即正常”代替。
5. **小步提交**：一个工作项一个提交，物理、运行时、界面的改动不混在同一提交。
6. **文档由测试守护**：README 与 DESIGN 中对物理行为的断言，必须对应至少一条自动化测试。

### 5.2 性能预算

下表数值来自 2026-11-19 在 Node 24.22.1 下的复测，作为施工前后对照的基线；浏览器环境受渲染与 DOM 影响，单独按帧时间统计。

| 指标 | 当前实测 | 施工目标 |
| --- | --- | --- |
| 单子步物理 | 0.048 ms，88 次 suspEval | 不超过 0.05 ms，suspEval 降到 30 次以内 |
| 每帧物理（8 子步） | 0.38 ms | 不超过 0.4 ms |
| simBuildModel | 0.070 ms | 不超过 0.05 ms，单独统计 |
| computeStatic | 7.86 ms | 不超过 8 ms，且只在重建时调用 |
| simCreate（settle 1.5 s） | 55 ms | 不超过 60 ms |
| 静态自检 | 22 ms | 按 setupRevision 缓存，参数不变时不重算 |
| 动态自检 | 572 ms | 移出周期路径，按需执行并分片 |

性能优化的验收必须同时满足数值不变：在优化前后用同一组确定性用例比对最终状态，要求逐位相同。

### 5.3 关键裁决

下表汇总 r2 采纳的裁决。分册与主册冲突时以此为准；实现与裁决冲突时，先改契约再改代码。

| 编号 | 议题 | 裁决 |

| R-01 | 脉冲力臂 | 作用点定为参考点前方 0.95 m，绕质心力臂为 offset − cgBody，默认 [1.10975, −0.30, 0]，俯仰脉冲力矩 −6880.45 N·m。5890 是缺陷症状，不是基线；全部脉冲类阈值重定 |

| 几何原子替换引发闪烁 | B3-2 合并 | 视觉抖动 | 提交在单个 rAF 任务内完成，浏览器不绘制中间态 |
| 性能优化改变数值结果 | B3、B4 | 确定性被破坏 | 优化前后 bit-identical 对照 |
| 分册与主册再次漂移 | B5 | 审查结论不可信 | 契约表唯一来源，文档断言逐条绑定测试编号 |

## 7.1 阶段三准入条件

1. 12 项缺陷均有对应回归用例，且在修复前失败、修复后通过。
2. 自由刚体解析轨迹、动量与能量不变量、接地点唯一性、运动比连续性四类测试通过。
3. 接口冻结：状态、角点、ForceEvaluation、遥测快照的字段与语义稳定；渲染层不写物理状态。
4. 文档中的物理断言与测试编号一一对应。
5. 性能预算达标，且优化前后确定性一致。
6. 单文件构建通过，index.html 与源码哈希一致，无新增运行时依赖。

## 8. 提交与版本

1. 每个工作项一个提交，消息格式为 `fix(physics|runtime|ui|tooling|docs): 摘要`。
